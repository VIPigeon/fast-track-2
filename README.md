# ХЛАМБАРД
Визуальная новелла, в которой вы торгуетесь с посетителями за всякий хлам. Для большинства людей это совершенно ненужные вещи, но если найдется человек, которому это нужно, он будет готов заплатить за нее __действительно__ большие деньги — речь идет о трехзначных суммах!

Игра очень короткая. Сначала три персонажа подходят для продажи вещей, потом еще два покупают. Концовка зависит только от вашей суммы денег — постарайтесь заработать как можно больше
